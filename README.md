# AWS Solutions Architect Associate Revision Site

This folder contains a revision sheet for the AWS Solutions Architect Associate (SAA-C03) certification, structured similarly to the AWS Cloud Practitioner revision sheet.

## Main files

- `index.html`: The main revision page with domains, technologies, exam topics, and in-scope services.
- `index.md`: Markdown version of the revision sheet.
- `AGENTS.md`: Behavioral guidelines (from the original context).

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload the contents of this folder to the repository root.
3. In GitHub, open `Settings` > `Pages`.
4. Under `Build and deployment`, choose `Deploy from a branch`.
5. Select the `main` branch and the `/ (root)` folder.
6. Save, then wait for GitHub Pages to publish the site.

## Usage

Open `index.html` in a browser to view the revision sheet. It includes links to official AWS documentation for each service.
